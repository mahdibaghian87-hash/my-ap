Glass Player - PWA package
1. Upload ALL files of this folder to a GitHub repository (github.com -> New repository -> Add file -> Upload files).
2. Settings -> Pages -> Deploy from branch (main, root). You get https://USERNAME.github.io/REPO/
3. Open that link in Chrome on Android -> menu -> Install app.
4. For a real APK: go to pwabuilder.com, enter the link, choose Android package, download.
